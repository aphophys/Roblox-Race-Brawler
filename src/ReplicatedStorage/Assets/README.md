# Assets

Not synced via `$path` — declared directly in `default.project.json` as empty,
`$ignoreUnknownInstances = true` Folders. Populate these by dragging in
built assets (meshes, GUIs, particle templates) directly inside Roblox Studio;
Rojo will not delete or overwrite them on sync.

- `UI_Templates` — cartoony bubbly labels, HUD buttons
- `Track_Library` — modular road segments with collision barriers
- `FanBox_Templates` — modular spectator pods/stands
- `VFX_Library` — particle effects for deposits, poses, and skills
